# 🌻 SunFlower

SunFlower is a beautifully organized visual platform designed to help users capture, collect, and grow the ideas that move them. Whether it's curating recipes, saving home inspiration, organizing style finds, or planning travel dreams, SunFlower provides a seamless, aesthetically pleasing workspace to gather inspiration.

---

## 🚀 Features

*   **Smart Boards:** Dedicated layouts tailored for **Recipe boards**, **Home inspiration**, **Style finds**, and **Travel dreams**.
*   **AI Curation:** Experience new, AI-curated boards matching your mood to discover ideas you'll actually love.
*   **One-Click Save:** Instantly capture inspiration from anywhere and add it to your visual feed.
*   **Analytics Dashboard:** Track engagement, views, saves, and likes on your shared boards with clean visual charts.

---

## 🛠️ Tech Stack (Suggested)

*   **Frontend:** React / Next.js, Tailwind CSS
*   **Deployment:** Netlify
*   **Icons:** Lucide React / Heroicons
